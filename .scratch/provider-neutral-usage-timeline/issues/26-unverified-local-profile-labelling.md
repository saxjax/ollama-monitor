# Unverified local profile labelling

Type: grilling
Status: resolved

## Question

Because local VS Code Insiders records do not establish a GitHub account
identity, should V1 present them as one explicitly unverified local Copilot
profile, allow a user-owned label for recognition, or require a separate
Provider Billing read before a work/personal account profile can be assigned?

## Answer

V1 presents the local source as one explicitly unverified Copilot profile,
such as "VS Code Insiders · Copilot (account unverified)". The user may rename
that local label for recognition, but it remains unverified. Only a separate
Provider Billing read may establish a Work/Personal account profile.
