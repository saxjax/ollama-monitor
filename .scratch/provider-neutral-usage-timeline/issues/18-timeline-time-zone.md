# Timeline time zone

Type: grilling
Status: resolved

## Question

Which time zone defines the Usage timeline's days, month boundaries, 30-minute
slots, and reference-month alignment, especially when events were recorded
while the user travelled or daylight-saving time changed?

## Answer

Usage events retain absolute timestamps. The user selects a timeline time zone,
defaulting to and initially following the computer's current zone; the choice
is remembered. That time zone defines days, month boundaries, 30-minute slots,
and reference-month alignment. The original local time is available in
drill-down only.
