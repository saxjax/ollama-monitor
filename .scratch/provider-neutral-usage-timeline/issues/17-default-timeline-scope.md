# Default timeline scope

Type: grilling
Status: resolved

## Question

When the user opens the Usage timeline, should the default scope be the last
selected Provider/account profile in its Native unit, or a Combined view across
available Providers?

## Answer

The Usage timeline opens in the last selected Provider/account profile and its
Native unit—for example, Work Copilot in credits. If there is no remembered
scope, it opens the first available Provider/profile rather than a Combined
view. Combined views remain a deliberate switch for cross-provider comparison.
