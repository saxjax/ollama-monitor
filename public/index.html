SETUP / ACCESS / LINKS

Monitor help

Saxjax Monitor stays local. Use this guide to connect the clients you want to observe; nothing below changes your Copilot or Ollama account.

01 · Ollama gateway

Keep Ollama on its normal port and point the client you want to observe at the monitored gateway:

OLLAMA_HOST=http://127.0.0.1:11435 your-client-command
Open dashboardGateway URLInstall Ollama
02 · GitHub Copilot billing

For paid credits, configure either your organization seat or personal account. The token is stored in macOS Keychain; only non-secret identity settings are stored locally.

./configure-copilot.sh organization YOUR_ORG YOUR_GITHUB_USERNAME
./configure-copilot.sh user YOUR_GITHUB_USERNAME

Required token access: organization Administration: read; personal account Plan: read. GitHub billing remains authoritative when available.

Create fine-grained tokenReview tokensCopilot billing docs
03 · Copilot capture sources

Leave Saxjax Monitor running while using the clients. It watches new local structured sessions—no proxy or editor extension is required.

  • Copilot CLI: ~/.copilot/session-state/
  • VS Code: ~/Library/Application Support/Code/User/workspaceStorage/
  • VS Code Insiders: ~/Library/Application Support/Code - Insiders/User/workspaceStorage/

VS Code values are exact when the journal provides token metadata. CLI input is labelled reconstructed when the final server payload is not locally available. Missing token counts are shown as estimates.

Copilot overviewVS Code Copilot docsCopilot CLI docs
04 · Local estimates and controls

Set your monthly Copilot budget and optional custom USD/1M token price in the Copilot panel. Ollama tokens are shown separately as local/free and never enter paid Copilot calculations.

When GitHub billing is unavailable, paid values are marked ≈ LOCAL ESTIMATE and use only Copilot traffic observed on this Mac. Clear view deletes the monitor’s local copies, not the source client histories.

05 · How to read the monitor

PAID · GITHUB COPILOT contains Copilot credits, billed dollars, and Copilot-only input/output tokens. LOCAL / FREE · OLLAMA contains Ollama tokens and is never included in Copilot billing.

Exact values come from the client or GitHub. Values prefixed with ≈ are estimates. VS Code can provide client-rendered context; Copilot CLI context may be reconstructed from its transcript. Server-only additions and cache accounting may not be visible locally.

The velocity panel uses recent Copilot traffic. GitHub billing is the budget baseline when available; otherwise the entire paid estimate is local. Runway and parallel capacity describe a budget burn-rate scenario, not a technical concurrency limit.

06 · Install, update, and troubleshoot
./install.sh

Installation builds the self-contained app in ~/Applications/Saxjax Monitor.app and registers a LaunchAgent. After updating the checkout, run the installer again, then quit and reopen the app from Applications or Spotlight.

  • No Spotlight app: rerun ./install.sh, then reopen Spotlight and search “Saxjax Monitor”.
  • No Ollama traffic: confirm the client uses port 11435 and Ollama itself remains available on 11434.
  • No Copilot traffic: keep the monitor running and start a new CLI/editor request; existing sessions are not imported at startup.
  • No billing: review the token link in the Copilot panel and verify the required read-only permission.

Use Clear view to delete monitor-owned history. It does not erase the original Copilot CLI, VS Code, VS Code Insiders, or Ollama source history.
