# Provider evidence fallback

Type: grilling
Status: resolved

## Question

When a Provider cannot supply an authoritative Billing read, which Display units
remain available and what evidence label must the Usage timeline show for each?

## Answer

Tokens remain available whenever the client can observe token usage. Provider
native unit is unavailable without Provider-supplied evidence. Dollars remain
available only as a clearly labelled local Monetary estimate derived from a
price schedule; it must never be presented as authoritative billing.
