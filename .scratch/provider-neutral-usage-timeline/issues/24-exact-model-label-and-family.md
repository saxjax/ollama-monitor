# Exact model label and family

Type: grilling
Status: resolved

## Question

When a Client record provides an exact model label as well as a broader model
family, should V1 retain and show the exact label in drill-down while using the
family only for stack colour and aggregation?

## Answer

V1 retains the exact Client-reported model label and shows it in Session and
request drill-down—for example, Claude Opus 4.8. Model family is a separate,
derived grouping used only for stack colour and aggregation.
